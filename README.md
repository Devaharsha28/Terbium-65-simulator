# Terbium 65

Terbium 65 is a digital logic simulation project focused on experimenting with **ternary computing and digital logic**.

## About

Terbium 65 is being developed as an environment for experimenting with **ternary logic, ternary circuits, and alternative approaches to digital computation**.

The goal is to provide a practical platform for designing, testing, and exploring ternary logic systems.

## Development

Terbium 65 is an ongoing project, with new features, improvements, and experimental capabilities being added over time.
